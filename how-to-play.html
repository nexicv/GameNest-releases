How to play

Host a lobby, share a join code, and get your friends into the same game.

Download GameNest Read the FAQ

Host and join

  1. 1

    Host a lobby

    Turn on Host through relay for online play, then select Host Game.

  2. 2

    Share the join code

    Friends enter the six-character code in Host IP or code and select Connect.

  3. 3

    Pick a game and start

    Choose a game in the lobby and start the match. For board games, the host installs the game pack and guests need the app.

Same screen
Choose local play in Chess or any of the ten board games—GameNest remembers your solo or local choice across games.
LAN or Tailscale
Join with the host’s address and port 47631. Realtime 3D matches such as Practice Range connect directly over LAN or Tailscale; guests without the signed package see an Install button with the download size in the lobby.
Suggest a game
Guests can click a game in the lobby to suggest it, and the host sees who wants what.
