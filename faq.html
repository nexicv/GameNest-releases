How to play Downloads

Install and update

Which download should I choose?

Windows and macOS come as ZIPs, Linux as a TAR.GZ, and Android as an APK. Each platform ships its own build, so the version beside each download is the one you get. Windows, Linux, and macOS host and join; Android hosts and joins too; the iPhone preview joins only, and its unsigned IPA needs your own signing before it will install.

How do I install and open it?

On Windows, extract the ZIP and open GameNest.exe; the packaged build needs no Rust or Python. On Linux, extract the tarball and run ./GameNest (requires glibc 2.35 or newer, such as Ubuntu 22.04+, Debian 12+, or Fedora 36+, and an X11 or Wayland desktop). On macOS, unzip and open GameNest.app, then allow it once in System Settings → Privacy & Security → Open Anyway. On Android, install the APK and allow Install unknown apps when prompted. On iPhone, sign the unsigned IPA with your own Apple ID using AltStore or SideStore (free Apple ID signatures refresh every 7 days, and iOS builds do not self-update).

How do I add or update games?

Open Settings → Manage games to install, update, or remove a game, or open the Add-ons list on desktop to install optional extras such as the Stockfish 19 engine for Chess (Chess works without it, and Android omits Stockfish). In the current Linux (0.11.6) and macOS (0.11.0) releases that catalog does not load, so install the platform's game packs ZIP from Downloads instead, beside the GameNest program on Linux or in ~/Library/Application Support/GameNest on macOS. Incompatible means the game needs a newer GameNest, so update the app first. GameNest will not install or replace a game while you are hosting or in a match, and it keeps the last two backups. The Android app includes eleven games, so a phone host needs no packs for those. If Manage games cannot load the catalog on Windows, the game packs ZIP on the download page can be extracted into the app folder; installing offline needs a copy you downloaded earlier.

Downloads and game packs
Can I edit Jeopardy clues or Task Knockout tasks?

Yes. Open Settings → Manage games → Tools → Edit games… to edit a game's declared clue or task files directly inside GameNest. The editor checks JSON before saving and keeps a backup of the previous file.

How do I uninstall GameNest?

On desktop, open Settings and choose Uninstall GameNest. After confirmation, GameNest closes and removes the launcher, portable settings, caches, update files, and installed game packages from the app folder.

What happens if our versions differ?

Different platforms ship different versions, so an older guest can meet a newer host. Update from the official Downloads section first. On Windows, choose Update & restart to install the update and rejoin the lobby, or Later to defer it. That host-to-guest update is an optional fallback and is unsigned, so accept it only from a host you trust.

Host and join

How do we host and join a game?

One person enters a name and selects Host Game. The lobby holds 2-16 players and uses port 47631 by default. Friends open GameNest, type the host's address or join code into Host IP or code, and select Connect. Two copies on one computer can connect over 127.0.0.1. On Android, Host on this phone starts the same lobby with the join code already on.

Full hosting steps
Should we use a join code or a LAN/Tailscale address?

Use a join code when players are not on the same network and you do not want port forwarding or Tailscale. Tick Host through relay before hosting, then share the six-character code. In a relay lobby, and in the board games it carries, players do not see each other's IP addresses; the relay receives their connections instead, and the extra hop through Milan adds latency. Realtime 3D matches are the exception: they need a direct connection to the host, so your app receives the host's address, usually a LAN or Tailscale one, even when you joined by code. The relay does not carry the gameplay. Use LAN or Tailscale when everyone is on one network or tailnet, and join with the host's address and port 47631. Joining by IP still works while relay hosting is on. Some games might need Tailscale or a local LAN to work effectively; joining by code is viable but less preferred.

What does a guest need installed?

For board and party games, only GameNest—guests do not need game packs, source code, or a compiler. The host installs the games from Settings → Manage games, runs the rules, and sends each player their screen. Realtime 3D games such as Practice Range run on every player's PC, so guests without the package see an Install button with the download size on Ready; realtime 3D packages are signed and verified at install and before each launch.

Fix a connection

Why can't my friend connect?

Check that the guest typed the host's address and port, or the six-character join code, into Host IP or code. Each new build may trigger a network access prompt; accept it, and check firewall or Tailscale settings if a remote friend still cannot connect. A test on the same network does not prove a remote friend can connect. If the relay cannot be reached, the lobby says so and joining by IP still works. A phone host must keep GameNest in front, because Android may stop the app when you switch away.

Can we continue after a disconnect?

If a guest drops during a match, their seat and board are kept and actions pause. Use Reconnect to this session from the same running app; closing the app loses its seat token. End Lobby closes the session for everyone.
