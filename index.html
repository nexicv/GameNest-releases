How to play

One person hosts. Everyone else joins from their own copy of GameNest.

  1. 1

    Host a lobby

    Turn on Host through relay for online play, then select Host Game.

  2. 2

    Share the join code

    Friends enter the six-character code in Host IP or code and select Connect.

  3. 3

    Pick a game and start

    Choose a game in the lobby and start the match. For board games, the host installs the game pack and guests need the app.
