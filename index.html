Do I need a game pack?

On Windows, install games from Settings → Manage games. If that catalog cannot load, the Windows game packs ZIP below is a manual fallback. The current Linux (0.11.6) and macOS (0.11.0) releases cannot load that catalog at all, so install from their game packs ZIPs. Android ships its games inside the app. Offline installation needs a copy of the ZIP you downloaded earlier.

Hosts of board games need the game installed. For Practice Range, each player installs a copy of the game.

Windows game packs ZIP Linux game packs ZIP: extract beside the GameNest program macOS game packs ZIP: extract into ~/Library/Application Support/GameNest
