# GameNest releases

Public app and game downloads for GameNest. The source repository remains private.

- **GameNest-v0.5.8.zip**: app ZIP; every player uses this.
- **GameNest-v0.5.8-games.zip**: manual all-games fallback for hosts.
- Game catalog releases: download games from **Settings -> Manage games** in GameNest 0.5.8 or newer.

Release assets are verified by the app. Use the in-app update and game manager where possible.
