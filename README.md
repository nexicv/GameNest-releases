# GameNest releases

Public app and game downloads for GameNest. The source repository remains private.

Pick the download for your system from the latest release:

- **Windows:** `GameNest-v<version>.zip`. `GameNest-v<version>-games.zip` is a manual all-games fallback for hosts.
- **macOS (Apple silicon and Intel):** `GameNest-v<version>-macos-app.zip` contains `GameNest.app` with the games included. The first launch needs **System Settings → Privacy & Security → Open Anyway** because the app isn't signed with an Apple developer ID.
- **Linux x64:** `GameNest-v<version>-linux-x86_64.tar.gz` is a portable folder with the games included. Extract it and run `GameNest`.

The `-macos.zip` and `-linux-x86_64.zip` files are used by the in-app updater. Game catalog releases (`games-*`) hold the individual games for **Settings → Manage games**.

Windows, macOS and Linux players can join the same lobby. Release assets are verified by the app; use the in-app update and game manager where possible.
